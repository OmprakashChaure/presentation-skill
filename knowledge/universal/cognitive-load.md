# Cognitive Load

## Purpose

Convert multimedia-learning principles into operational presentation rules for managing audience cognitive load.

## Scope

**Strongest applicability:** Educational, instructional, explanatory, technical teaching presentations.

**Weaker applicability:** Executive, sales, investor, marketing decks — apply selectively, not as rigid laws.

## Principles (Mayer's Multimedia Learning)

### 1. Coherence Principle

**Rule:** Exclude extraneous material — words, graphics, sounds not essential to the message.

- **Decision rule:** IF element does not directly support slide assertion → REMOVE
- **Anti-pattern:** Decorative images, background watermarks, "engaging" clip art, irrelevant quotes
- **Exception:** Branding elements (logo, footer) in designated areas only

### 2. Signalling Principle

**Rule:** Add cues to highlight organization and key information.

- **Slide level:** Assertion title signals main message
- **Within slide:** Bold, colour, callout boxes, arrows, numbering signal priority
- **Across deck:** Section dividers, progress indicators, consistent layout patterns
- **Rule:** Signals MUST be semantic — not decorative

### 3. Redundancy Principle

**Rule:** Do not present same information in multiple redundant forms simultaneously.

- **Forbidden:** Reading slides verbatim (spoken = on-slide text)
- **Forbidden:** Narration + identical on-screen text + identical caption
- **Allowed:** Narration + visual evidence + minimal keywords (assertion-evidence)
- **Rule:** On-slide text = keywords/evidence labels; narration = explanation

### 4. Spatial Contiguity Principle

**Rule:** Place related words and graphics near each other.

- **Chart:** Direct labels on elements (not separate legend)
- **Diagram:** Labels adjacent to shapes (not callout lines crossing)
- **Table:** Headers adjacent to data; units in header not each cell
- **Annotation:** Callout points to specific element, not floating

### 5. Temporal Contiguity Principle

**Rule:** Present related words and graphics simultaneously.

- **Animation:** Reveal assertion → evidence → implication in sequence (not all at once)
- **Builds:** Use progressive disclosure for complex diagrams (step-by-step)
- **Forbidden:** Show evidence before assertion (audience doesn't know what to look for)

### 6. Segmenting Principle

**Rule:** Break complex content into learner-paced segments.

- **Slide count:** Prefer more slides with less content each
- **Complex process:** One step per slide (or per build)
- **Complex diagram:** Layered reveal (structure → labels → flows → details)
- **Rule:** Each segment = one cognitive step

### 7. Pretraining Principle

**Rule:** Ensure audience knows key concepts/terms before main explanation.

- **Agenda slide:** Preview key terms/concepts
- **Glossary slide:** Appendix with definitions
- **Prior knowledge check:** "You already know X; today we extend to Y"
- **Rule:** Do not assume shared vocabulary — define or reference

### 8. Modality Principle (Where Relevant)

**Rule:** Use narration + graphics rather than on-screen text + graphics.

- **Live presentation:** Speaker narrates; slides show evidence/keywords
- **Distributed/read deck:** Slides must stand alone — use assertion + evidence + annotation
- **Hybrid:** Design for read mode; speaker adds narration layer

## Operational Rules by Presentation Type

| Principle | Educational/Technical Teaching | Executive/Sales/Investor/Marketing |
|-----------|--------------------------------|-------------------------------------|
| Coherence | Strict — remove all non-essential | Moderate — branding, persuasion elements allowed |
| Signalling | Strong — explicit structure cues | Moderate — assertion titles, section dividers |
| Redundancy | Strict — no narration=text | Flexible — slides often read standalone |
| Spatial Contiguity | Strict — direct labels, adjacent | Standard — direct labels preferred |
| Temporal Contiguity | Builds/animation for complexity | Minimal builds; static slides preferred |
| Segmenting | Strong — one concept per slide | Flexible — executive summary slides dense |
| Pretraining | Required — glossary, concept preview | Optional — assume business literacy |
| Modality | Design for narration + slides | Design for read mode primarily |

## Cognitive Load Budget

- **Working memory limit:** ~4±1 chunks simultaneously
- **Per slide:** 1 assertion + 1 evidence visual + up to 3 supporting chunks
- **Per deck:** Segment into 10–15 min modules with breaks/dividers
- **Metric:** If audience cannot reproduce slide message after 30 sec → overload

## Anti-Patterns

- Wall of text (violates coherence, segmenting)
- Chart with separate legend (violates spatial contiguity)
- Animation for decoration (violates coherence)
- Jargon without definition (violates pretraining)
- 10-step process on one slide (violates segmenting)
- Reading slides aloud (violates redundancy)

## Handoff to Other Layers

- **Storytelling (educational):** Enforces segmenting, pretraining, signalling
- **Layout:** Implements spatial contiguity via grid proximity
- **Charts/Diagrams:** Direct labelling, progressive reveal builds
- **Evaluation:** Checks chunk count, contiguity, redundancy, segmenting
