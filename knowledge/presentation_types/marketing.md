# Marketing Presentation Type

## Purpose

Define type-specific policies for marketing presentations.

## Scope

Campaign proposals, brand strategy, creative reviews, launch plans, channel strategies, performance reviews.

## Core Policies

### Target Audience Definition

- **MUST** define: Primary persona, Segment size, Pain points, Media consumption, Decision journey
- **Format:** "Primary: [Persona] — [Count] — [Key insight] — [Channel preference]"
- **Rule:** No "everyone" — marketing requires focus

### Insight-Driven

- **MUST** lead with consumer/market insight (not creative idea)
- **Format:** "Insight: [Observation] → Tension: [Unmet need] → Opportunity: [White space]"
- **Rule:** Creative without insight = decoration

### Positioning Statement

- **MUST** include: For [Target], [Brand] is the [Category] that [Benefit] because [Reason to Believe]
- **Rule:** Every creative execution must trace to positioning

### Message Hierarchy

- **MUST** define: Core message (1), Supporting pillars (2–3), Proof points per pillar
- **Format:** Message map — Core → Pillars → Proof
- **Rule:** No more than 3 pillars; audience retains 1–3 messages

### Creative Concept

- **MUST** show: Concept rationale, Execution examples, Adaptability across channels
- **Format:** Concept board + Rationale: "This executes [Pillar] by [Mechanism]"
- **Rule:** Creative must be explainable in 1 sentence linking to insight

### Evidence for Marketing Claims

| Claim | Required Evidence |
|-------|-------------------|
| Audience preference | Research data (quant/qual), source cited |
| Channel effectiveness | Historical performance, benchmarks, test results |
| Creative effectiveness | Pre-test scores, brand lift, engagement benchmarks |
| Budget efficiency | CAC by channel, ROAS, attribution model |

### Channels & Activation

- **MUST** specify: Channel, Role in funnel, Budget %, KPI, Owner, Timeline
- **Format:** Channel plan table
- **Rule:** No channel without funnel role + KPI

### Call to Action (CTA)

- **MUST** define: Primary CTA (per audience/channel), Measurement, Attribution
- **Format:** "CTA: [Action] → Track: [Metric] → Attribute: [Method]"
- **Rule:** No "brand awareness" without proxy metric (search lift, direct traffic, aided recall)

### Brand Constraints

- **MUST** reference: Brand guidelines (logo, colour, tone, voice, photography style)
- **Rule:** Creative operates WITHIN constraints; constraints are not suggestions

## Slide Type Defaults

| Purpose | Slide Archetype |
|---------|-----------------|
| Audience insight | Assertion-Evidence (research finding) |
| Positioning | Assertion-Evidence (statement + proof) |
| Message map | Comparison (Core → Pillars → Proof) |
| Creative concept | Image-led (concept boards) |
| Channel plan | Table + Timeline |
| Budget allocation | Chart (Pie/Waterfall) |
| Measurement plan | KPI dashboard |
| Creative review | Image-led (executions) |

## Narrative Default

- **Primary:** Marketing pattern (Audience → Insight → Positioning → Message → Creative → Channels → CTA → Measurement)

## Design Adaptations

- **Density:** Low — visual, inspirational, high-quality imagery
- **Brand fidelity:** High — exact brand colours, fonts, imagery style
- **Creative space:** Generous — let creative breathe
- **Appendix:** Research detail, creative variants, media plan detail

## Anti-Patterns (MUST PREVENT)

- Disconnected creative decoration (pretty but no insight link)
- No audience definition
- Insight not sourced
- Message map >3 pillars
- Creative not adaptable across channels
- Channels without funnel role/KPI
- CTA without measurement
- Brand guidelines ignored
- Budget without expected outcome

## Handoff to Other Layers

- **Reasoning:** Enforces insight-first, message hierarchy, creative-insight link
- **Narrative-patterns:** Marketing pattern
- **Slide-types:** Insight, Positioning, Message Map, Creative, Channel Plan, Measurement
- **Visualization:** Funnel charts, channel mix, brand lift, attribution
- **Evaluation:** Checks: Insight sourced, positioning complete, message hierarchy ≤3, creative linked to insight, channels have KPIs, CTA measurable, brand compliant
